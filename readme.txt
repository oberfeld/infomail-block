Zeigt eine Auswahl von Beiträgen fürs Oberfeld-Infomail an

== Installation ==

- Version in `package.json` und `infomail-block.php` anpassen
- `build-zip.sh` ausführen.
- Erstelltes `infomail-bock-?.?.?.zip` als Plugin hochladen.
